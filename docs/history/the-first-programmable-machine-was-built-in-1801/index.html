The First Programmable Machine Was Built in 1801

Published 2026-11-06 · Watch on YouTube

What the video says

The first computer code was woven in cloth. You think punch cards started with mainframes. In 1801, a French weaver built a programmed loom. Joseph Marie Jacquard used wooden cards with holes. Each hole told the machine how to loop the thread. This binary system invented modern data. Check your desk printer for paper feed gears.
