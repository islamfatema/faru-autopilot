Rome Had Express Delivery - Only the State Could Use It

Published 2026-09-14 · Watch on YouTube

What the video says

Rome had express delivery. You just weren't allowed to use it. Augustus set it up: the cursus publicus, the state courier service. Along Roman roads, stations had fresh animals and beds for couriers. Officials, orders and state goods crossed the empire. But you needed a government pass. Your own letters? Hand them to a friend who's travelling.
